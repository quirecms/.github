# Getting help

- **Documentation:** start with the [README](https://github.com/quirecms/framework#readme) and the guides in [docs/](https://github.com/quirecms/framework/tree/main/docs): extensions, themes, content, settings, the database, backups and Docker.
- **Bugs:** if something doesn't work as documented, [open an issue](https://github.com/quirecms/framework/issues/new/choose) with the steps to reproduce it.
- **Feature requests:** open an issue describing the problem you want to solve.
- **Security issues:** follow the [security policy](SECURITY.md); don't open a public issue.
- **Anything else:** write to [hello@quirecms.com](mailto:hello@quirecms.com).

Quire is in early development and maintained by a small team, so answers can take a few days.
