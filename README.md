# quirecms/.github

Files that apply to the whole [Quire](https://github.com/quirecms) organisation on GitHub:

| Path | What it is |
|------|------------|
| `profile/README.md` | The organisation's profile page on GitHub |
| `brand/` | Logos, colours and how to use them |
| `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md` | Defaults for every repository that doesn't have its own |
| `.github/ISSUE_TEMPLATE/`, `.github/pull_request_template.md` | Default issue forms and pull request template |
